9세 어린이용 1:1 공룡 대전 게임입니다. 설치 없이 브라우저에서 실행합니다.

## 온라인에서 바로 플레이

## 실행 방법
- `index.html`을 더블클릭하면 크롬/엣지에서 바로 실행됩니다.
- 배경음악과 효과음은 첫 키를 누르면 나옵니다 (브라우저 정책). `M` 키로 켜고 끕니다.

## 조작법
| 키 | 동작 |
|---|---|
| ← → | 이동 |
| ← ← / → → (빠르게 두 번) | 그 방향으로 대시 — 잔상을 남기며 쌩 이동, 잠깐 무적이라 공격을 피함 |
| 뒤로 **꾹** | 가드 (피해 크게 감소) |
| ↑ | 점프 — 땅 공격을 피함. ← 또는 →를 누른 채 점프하면 그 방향으로 멀리 뜀 (공중에서도 방향 조절 가능) |
| 점프 중 ↑ 한 번 더 | 2단 점프 — 더 높이 뛰어 상대를 넘어가 위치를 바꿈 (한 번만 가능) |
| ↓ | 웅크리기 — 높은 공격(물기)을 피함 |
| Z | 빠른 공격 |
| X | 강한 공격 |
| ↓ + Z | 낮은 공격 |
| ↓ + X | 올려치기 (점프한 상대도 맞춤) |
| 점프 중 Z/X | 공중 공격 |
| C | 필살기 (게이지가 가득 찼을 때) |
| Enter | 시작 / 일시정지 |
| Esc | 뒤로 가기 |
| M | 음악 켜기/끄기 |

## 빠른 공격 vs 강한 공격
- **빠른 공격(Z):** 살짝 웅크렸다가 툭 튀어나가며 잔상을 남기고, 불꽃·작은 충격파와 "탁!"이 나옵니다 (강한 공격의 절반 정도 크기).
- **강한 공격(X, ↓+X):** 몸을 뒤로 젖히며 힘을 모으고(머리 앞에 주황 빛) → 앞으로 크게 늘어나며 내지릅니다. 맞히면 큰 섬광·충격파·화면 확대·긴 멈춤과 함께 "쾅!"이 나옵니다.

## 아이패드(터치) 조작
터치 기기에서는 화면 버튼이 자동으로 나타납니다 (반투명).
- **좌하단 십자 버튼:** ◀ ▶ 이동(빠르게 두 번 = 대시 회피, 상대 반대쪽을 꾹 = 가드), ▲ 점프, ▼ 웅크리기
- **우하단:** ↑ 점프(◀/▶를 누른 채 누르면 그 방향으로 점프, 공중에서 한 번 더 누르면 2단 점프로 상대 넘기), Z 빠른 공격, X 강한 공격, C 필살기(쓸 수 있으면 공룡 색으로 빛나며 커졌다 작아짐, 아직이면 흐리게 + 테두리에 게이지 진행 표시. 모자랄 때 누르면 "게이지가 아직 부족해요" 안내)
- **멀티터치:** ▼를 누른 채 Z = 낮은 공격, ▼ + X = 올려치기 / 점프 중 Z·X = 공중 공격
- **상단 ❚❚:** 일시정지 (화면을 누르면 계속)
- **메뉴:** 카드를 눌러 고르고 노란 버튼으로 결정, 좌하단 ↩ 뒤로, 우상단 ♪ 음악 켜기/끄기
- 가로 화면에서 플레이합니다. 사파리에서 "홈 화면에 추가"하면 주소창 없이 전체 화면으로 실행됩니다.

## 공룡 8종과 기술 (기술 이름은 아이가 직접 지었어요)
| 공룡 | Z (기본 1) | X (기본 2) | C 필살기 |
|---|---|---|---|
| 티라노사우루스 | 티라노 풀스매싱 꼬리치기 | 티라노 씽 음파 발사 (날아가는 음파) | 메가 바이트 물기 (돌진 3연속 물기) |
| 트리케라톱스 | 트리케라 쿵쿵거리기 (땅 충격파 2번) | 트리케라 쉴드 프릴 방어 (막으면 피해 0·상대 휘청) | 트리플 혼 어택 (뿔 박치기) |
| 스테고사우루스 | 풀스윙 (꼬리 크게 휘두르기) | 스테고 레이저 (화면 끝까지 광선, 웅크리면 피함) | 롤링 스매싱 (공처럼 굴러 4연타) |
| 안킬로사우루스 | 지진 일으키기 (땅 충격파) | 롤링 안킬로 스매싱 (굴러서 들이받기) | 아머 해머 꼬리치기 (곤봉 꼬리 2연타) |
| 스피노사우루스 | 스피노 롤링 (굴러가며 공격) | 워터 바이트 (물 튀기며 물어뜯기) | 워터 토네이도 (물 회오리 4번 휘감기) |
| 테리지노사우루스 | 독깃털 날리기 (독: 1초마다 6, 독으로는 안 쓰러짐) | 미스터리 스트링 (줄로 잡아 들어 올렸다 쿵!) | 나이트 스매싱 (발톱 6연타) |
| 파키케팔로사우루스 | 스피드 턴 (맞으면 어질어질 잠깐 못 움직임) | 파키케 쉐도우 분신술 (그림자 분신 2마리 돌진) | 스톤 헤드 박치기 (높이 뛰어 박치기) |
| 프테라노돈 | 프테라 윙 날개치기 | 부리 쪼기 (콕콕콕 3연타) | 프테라 애로우 (화살처럼 일직선 돌진) |

참고: 프테라노돈은 공룡이 아닌 익룡이며, 떠 있어서 낮은 공격에 맞지 않습니다.

## 프로젝트 구조
```
dino-duel/
├── index.html      # 화면과 스크립트 연결
├── js/
│   ├── core.js     # 화면 크기, 키 입력, 그리기 도우미(피부 질감·눈·이빨·뿔)
│   ├── audio.js    # 배경음악(타이틀/배틀/승리/패배)과 효과음, WebAudio 합성
│   ├── dinos.js    # 공룡 8종 그림 + 능력치 + 기술 데이터
│   ├── touch.js    # 아이패드 터치 조작 (십자·점프·공격 버튼, 메뉴 터치)
│   └── game.js     # 전투, 회피, CPU, 필살기 연출, 화면(선택/난이도/대결)
├── README.md
├── tools/
│   ├── serve.js    # 로컬 개발 서버 (127.0.0.1:5173, 이미지 저장 기능 포함)
│   └── cutout.html # AI 이미지 배경 제거·자르기 도구
├── concept/        # 디자인 시안
└── assets/         # 실사 이미지 (raw/ 에 원본)
```

## 실사 이미지로 교체하기
`assets` 폴더에 아래 이름으로 PNG를 넣으면 코드 그림 대신 자동으로 사용됩니다. 없는 파일은 기존 그림을 씁니다.

- 공룡: `<키>_idle.png`(기본), `<키>_attack.png`(공격) — 오른쪽을 보는 전신 옆모습, 투명 배경
- 키: `trex`, `trice`, `stego`, `ankylo`, `spino`, `theri`, `pachy`, `ptera`
- 경기장 배경 (16:9): `bg_forest.jpg`, `bg_meadow.jpg`, `bg_desert.jpg`, `bg_lava.jpg`, `bg_meteor.jpg` — 난이도 화면에서 미리보기를 보고 고릅니다 (키보드: ↑↓로 줄 바꾸기, ←→로 고르기 / 터치: 미리보기를 누르기).
- AI 도구가 체크무늬를 그려 넣은 "가짜 투명" 이미지도 됩니다: `assets/raw/<키>_idle.webp`, `<키>_attack.webp`를 넣고 개발 서버에서 `tools/cutout.html?keys=<키>`를 열면 배경을 지우고 두 장을 같은 크기로 잘라 `assets/`에 저장합니다. 배경은 `assets/raw/bg_<이름>.webp`를 넣고 `?bg=forest,lava`처럼 붙이면 워터마크를 덮어 `bg_<이름>.jpg`로 저장합니다.
- 이미지 생성 프롬프트: `IMAGE_PROMPTS.md`
